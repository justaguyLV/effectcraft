# How the repository works

This repository does **not** contain a copy of Copper Launcher. It contains a *recipe*:

```
.github/workflows/copper.yml   build, sign, release, emulator test
copper-custom/
  apply.sh            runs every step below on a Copper checkout
  gen_palette.py      blue/white Material 3 palette (light and dark)
  look.py             surface styles and corner roundness (theme overlays)
  studio.py           Color Studio wiring (resources, activity, settings entry)
  fonts.py            font families, overlays, Arabic default, font import entry
  look_share.py       "Share my look" entries
  hotbar.py           hotbar touch-area fix and diagnostic overlay
  rtlfix.py           right-to-left fixes (account name, settings button)
  translate_ar.py     Arabic text for strings Copper ships without it
  gen_notices.py      notices generated from the bundled mods
  build-mods.sh       Fabric Loader, Fabric API, Meteor and performance mods per Minecraft version
  fetch-fonts.sh      fonts from Google Fonts (list in fonts.txt)
  java/               the classes BlockComet adds (Studio, Fonts, Look, About activity logic)
  NOTICES.txt         template of the in-app licenses text
  logo.png            app icon source
```

`apply.sh` is idempotent only on a fresh checkout: each script patches known text in Copper's files and **fails loudly** if the
anchor text is not there (so an upstream change breaks the build instead of silently producing a different app).

## What changes inside Copper

| Area | Change |
|---|---|
| Resources | app name, palette, icons, strings (English and Arabic), new `values`, `font`, `xml` files |
| `ThemeManager` | defaults (own palette, light mode), calls to the look, font and Color Studio code |
| `Instances` / `AsyncAssetManager` | on first start, one "Meteor *version*" instance per bundled version, mods copied into it |
| `LauncherPreferenceAppearanceFragment` | new settings entries and their handlers |
| `HotbarView` | real hotbar size and slot offsets, diagnostic overlay |
| Layouts | right-to-left fixes |
| Manifest | right-to-left support, the Color Studio activity, per-app language storage |

New classes (in `copper-custom/java/`): `BlockCometStudio`, `ColorStudioActivity`, `BlockCometFonts`, `BlockCometLook`;
`BlockCometAbout` is generated by `apply.sh`.

## Licensing consequence

The added classes call, and are called by, Copper's code and are compiled into the same app, so this repository treats them as part
of the same work and releases them under the LGPL-3.0 as well. See `NOTICE.md`.
